The dataset is made of Solomon-like Capacitated VRPTW instances with 100 customers each. Instances belong to three families: clustered (C), random (R), and mixed (RC), extended as described in the attached latex tables. Each instance is stored as a plain-text file following the standard Solomon format, containing a vehicle block with fleet size and capacity, and a customer block with coordinates, demand, time window, and service time. The depot is included as customer 0. There are 5,184 training instances and 1,296 test instances.
Each instance is paired with a semicolon-delimited CSV file encoding its Ng-set as a 100x100 binary matrix, where entry (i,j)=1 means customer j belongs to the neighborhood of customer i. Each row of the CSV corresponds to one customer. Multiple solution runs may be stored per file, identified by timestamp; only the most recent one is used. In total there are 6,480 individual Ng-set files, one per instance.
